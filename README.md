# BitterJava

** BitterJava is a purpousely VULNERABLE application. Only run BitterJava LOCALLY **

BitterJava is a purpousely vulnerable skeleton of a forum web app. It features users, logins, comments, searching, and profiles. Each feature of the forum hosts a vulnerability that is there to exploit. The vulnerabilities include but are not limited to: SQL Injection, Stored XSS, Broken Access Control, Weak Authentication.
